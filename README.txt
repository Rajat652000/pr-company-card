PR COMPANY 3D CARD

1. Rename your downloaded GLB file:
   pixelabs-glb-3347.glb  ->  pr-boy.glb

2. Put it here:
   pr-company-3d-card/models/pr-boy.glb

3. Do NOT double-click index.html for testing. Start a local web server.

Windows PowerShell / CMD (if Python installed):
   cd path\to\pr-company-3d-card
   python -m http.server 8000

Then open:
   http://localhost:8000

WSL/Linux:
   cd /path/to/pr-company-3d-card
   python3 -m http.server 8000
